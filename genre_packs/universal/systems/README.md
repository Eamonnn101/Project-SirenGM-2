# Universal · Systems (placeholder)

The universal genre pack intentionally ships **no** shared mechanical
systems. Power systems, social hierarchies, technology tiers, and
magic/cultivation/skill ladders are all novel-specific — they live in
`packs/<name>/novel_rules.md`, synthesized during ingest.

This directory exists only because `tools/lint_pack.py` requires at
least one `systems/*.md` file in a genre pack.

If a future need arises for *truly* cross-novel shared mechanics
(e.g. a universal save-state convention that every novel must honor),
add a file here. Until then, keep this directory minimal.
