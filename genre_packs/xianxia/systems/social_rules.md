# 社交规则 · Genre-level

通用于修仙题材。具体宗门的内部规矩由 user pack 的 `factions/<slug>.md` 定义。

## 宗门内称谓（默认）

- 外门对内门：**师兄 / 师姐**。
- 同辈之间：直接称名或加"师兄 / 师姐"。
- 真传长老：**长老 / 前辈**。
- **不可**随意称"师父"——除非已经正式拜师。"挂名弟子"类 NPC 的称谓由 user pack 定义。

## 通用宗规（默认）

- **私斗**：被执事发现会受罚。具体惩罚由 user pack 内该宗门的 faction 页定义。
- **盗取宗门资源**：废修为 / 逐出山门。
- **欺凌同门**：口角通常不管，动手即罚。
- **对凡人**：保持克制与礼貌是正道宗门的通行准则。魔修不受此约束。
- **对魔修**：正道对魔修的默认立场为"格杀"，但具体宗门可在 faction 页调整。

## 对话与欺骗

- 多数 NPC 对玩家的修为与气息有基本判断能力——说谎不易得逞。若玩家仍要说谎，GM 应通过 NPC 的怀疑表情、停顿、眼神来表现，不必立即揭穿。
- 贿赂与礼物可以奏效，但应在 save 的 `relationship_state.json` / `hidden_truths.md` 中留下后果（某 NPC 的隐式评价下降）。

## 玩家行为提示

- 玩家对陌生 NPC 保持基本礼貌是默认预期；过于粗鲁会扩散为外门弟子之间的私下议论，并影响多个 NPC 的 affinity。
- 特定 NPC 的语气偏好、禁忌、关心话题等在 user pack 的 character 页定义。
