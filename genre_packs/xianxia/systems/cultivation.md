# 修炼体系 · Genre-level

本文件定义修仙题材 user pack 共享的**境界阶梯**与**真气语言**。具体小说若采用不同命名（例如"聚气 / 凝神 / 结丹"），应在 user pack 的 `systems/cultivation.md` 中以**覆盖**方式重新定义，并保证映射到下列通用阶梯以便 GM 一致判断。

## 通用境界阶梯

1. **气感期**（一到九层）：感受天地灵气，打通经脉。
2. **筑基**：灵气成形于丹田。
3. **金丹**：灵气凝核。
4. **元婴**：神魂凝实，可离体。
5. **化神**：神魂与天地共鸣。
6. **渡劫**：触犯天威，生死一线。

若 user pack 在 `inherits_genre: xianxia` 之上沿用这一阶梯，则直接共用本体系；若有不同命名，应在 user pack 显式列出从旧名到通用阶梯的映射。

## 硬性规则

- 不可跳阶（见 `canon_guardrails.md`）。
- 每次升层需有契机。升层事件必须在 save 的 `session_log` 与 `world_state.json.player` 中留下可追溯记录。
- 20 回合内的 MVP 体验不应跨越一个大境界以上的修为——user pack 可以收紧但不应放宽。

## 真气语言

- **禁止数值表**。以"真气几乎见底"、"真气还余六七成"、"真气已无可用"描述。
- 连续战斗三息后应感到明显消耗。
- 真气恢复受到环境灵气密度、丹药、冥想时长的影响；不设公式。

## 功法与道具

- 具体功法、法器、丹药在 user pack 的 `systems/items.md` 或 entity 页面中定义。本 genre 文件只规定"这类物品存在"这一事实，以及它们遵循"代价换力量"的原则。
